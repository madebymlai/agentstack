# Workflow

Use `bd` (Beads Issue Tracker) to track specs, ADRs, and issues.

At the start of every session, run `bd prime`; it returns the live Beads workflow for this repository, including the current rules for specs, ADRs, and issues.

# Domain docs

Domain language and terminology defined in `CONTEXT.md` (or `CONTEXT-MAP.md`) of the repo root as local-only documentation.
