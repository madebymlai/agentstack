How the tools work together

The six tools aren't separate installs — they feed each other. beads holds the work: every ready issue, its dependencies, and what to pick up next. An agent claims one, then codebase-memory hands it a queryable graph of the code to plan against, and mattpocock/skills gives it a proven workflow to follow. tokf compresses the command output it reads back along the way, so a long session stays inside the context window.

When it is time to run code, sandcastle launches pi in a Docker, Podman, or Vercel sandbox and pulls the next ready issue straight from beads — closing the loop where it started. Because the same tools and rules are wired into each agent, the workflow is identical whether you run Claude Code, Codex, or OpenCode.
