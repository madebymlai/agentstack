agentstack AI coding agent setup

Set up your coding agents with one command.

The same tools and workflow across Claude Code, Codex, and OpenCode — no per-agent setup.

The tools feed each other. beads tracks the work and its dependencies; an agent claims a ready issue, reads the code through codebase-memory's graph, and follows a workflow from skills — while tokf keeps command output small enough to stay in context. The same setup gives every selected agent the same MCP servers, skills, permissions, and project conventions.
