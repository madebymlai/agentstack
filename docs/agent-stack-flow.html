agentstack — The Agent Stack & How It Fits Together

What npx agentstack installs, and how the pieces compose into one workflow across Claude Code, Codex, and OpenCode.

agentstack is a one-command setup tool for AI coding agents. A single npx github:madebymlai/agentstack installs a shared toolchain — token compression, a code knowledge graph, curated skills, a dependency-aware issue tracker, a minimal agent, and a sandbox orchestrator — then configures all of them for whichever agents you use. The result: Claude Code, Codex, and OpenCode all get the same brain.

What it installs

Six tools, each pulled from its own upstream repo and wired in for every selected agent.

ToolSourceRole in the stack
tokf mpecan/tokf Token-compression binary (GitHub release) plus per-tool hooks (tokf hook install --global). Compressed output is marked 🗜️; tokf raw last restores the full text. /agentstack generates filters under .tokf/filters/ or .tokf/rewrites.toml.
codebase-memory DeusData/codebase-memory-mcp Code knowledge-graph MCP server (codebase-memory-mcp), registered as an MCP server for each agent. Configured with auto_index true / auto_index_limit 50000 so graph queries (search_graph, trace_path, get_code_snippet) replace blind grep.
mattpocock/skills mattpocock/skills Curated agent skills installed globally per agent via npx skills@latest add mattpocock/skills -g, mapped to each agent (claude-code, codex, opencode).
beads (bd) gastownhall/beads Dependency-aware issue tracker binary. bd init --stealth creates a project .beads/ (Dolt DB, git-synced via refs/dolt/data; issues.jsonl is a passive export) without touching AGENTS.md or hooks. Ships a bundled /beads skill.
pi earendil-works/pi-mono @earendil-works/pi-coding-agent (npm install -g) — a minimal coding agent (4 tools, ~1K-token system prompt). Skill auto-discovery is disabled; pi is the default executor that sandcastle drives.
sandcastle @ai-hero/sandcastle Sandboxed agent orchestration over Docker / Podman / Vercel. sandcastle init --agent pi --template parallel-planner-with-review scaffolds .sandcastle/; agentstack points its plan prompt at bd ready --exclude-type=epic -l=ready-for-agent.

The stack, in four layers

Agents
Claude Code · Codex · OpenCode — pick any or all at install time (--claude, --codex, --opencode). Every tool below is configured for each agent you select, so the workflow is identical wherever you run it.
Instructions
AGENTS.md (principles template + the tokf convention) · CLAUDE.md (@AGENTS.md + beads integration + session-completion protocol) · CONTEXT.md (domain language). Tuned interactively by the /agentstack skill.
Live tools
beads (bd) — issues · codebase-memory — code graph (MCP) · tokf — output compression · mattpocock/skills — reusable workflows.
Execution
sandcastle orchestrates pi inside a Docker / Podman / Vercel sandbox using the parallel-planner-with-review template — planning, building, and reviewing work pulled straight from beads.

How it all fits together

One install, then the same loop for every task — and the same loop on every agent.

Install & configure npx agentstack

Select Claude Code, Codex, and/or OpenCode. agentstack installs the global tools, registers the codebase-memory MCP server and tokf hooks per agent, writes AGENTS.md / CLAUDE.md, and adds local-only ignores to .git/info/exclude.

npx github:madebymlai/agentstack npx github:madebymlai/agentstack --claude --codex --opencode npx github:madebymlai/agentstack --project # project files only
↓

Instruct AGENTS.md · CLAUDE.md

Every session loads the principles, the 🗜️ tokf convention, and the beads rules. Run /agentstack to probe the codebase and write principles, tokf filters, and sandcastle coding standards.

↓

Claim work beads (bd)

Pull unblocked, AFK-ready work from the dependency-aware tracker. Epics are containers — implement their children, not the epic.

bd ready --exclude-type=epic bd show <id> bd update <id> --claim
↓

Discover code codebase-memory

Navigate the auto-indexed knowledge graph instead of scanning files — search_graph, trace_path, get_code_snippet — and fall back to grep only for plain text and config.

↓

Build mattpocock/skills · tokf

Work through curated skills against the stack's principles. tokf compresses noisy command output (🗜️) so more of the task fits in context; tokf raw last recovers the full output when needed.

↓

Sandbox & review sandcastle · pi

Hand execution to sandcastle: it runs pi inside a Docker / Podman / Vercel sandbox via the parallel-planner-with-review template, pulling ready work directly from beads (bd ready --exclude-type=epic -l=ready-for-agent).

↓

Ship & remember beads (bd) · git

Close the issue, record durable insight, and complete the session protocol — work is not done until it is pushed.

bd close <id> bd remember "insight worth keeping" git pull --rebase && git push

Principles (the shared contract)

Written into AGENTS.md and applied by every agent, on every task.

SRP · OCP · LSP · ISP · DIP

The SOLID core — one reason to change, open for extension, substitutable, lean interfaces, depend on abstractions.

KISS · DRY

Favor simplicity; keep every piece of knowledge in one authoritative place.

Forward-First

Design for the current and next contract version — no backward-compat shims.

No Defensive Garbage

Trust established preconditions; let violated invariants fail loudly.

Tell, Don't Ask · Fail Fast

Tell objects what to do; surface faults at the interface where they originate.

No Silent Error Swallowing · Explicit Error Types

Every error is observable; each failure mode is a named, typed value.
