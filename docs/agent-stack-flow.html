How it works

1

Run one command

Run npx github:madebymlai/agentstack and pick the agents you use.

2

agentstack sets everything up

It installs the tools, registers the code-graph MCP server and tokf hooks, and writes your AGENTS.md and CLAUDE.md.

3

Every agent works the same

Claude Code, Codex, and OpenCode share the same tools, issues, skills, and principles.
